# CustomDisc Support Bot

Полноценный Telegram-бот поддержки на Python. Реализован на базе `python-telegram-bot` 20-й версии и использует SQLite для хранения данных о тикетах, сотрудниках и настройках.

## Возможности

- Приветственное сообщение `/start` в личном чате с ботом.
- Привязка основной группы поддержки командой `/link` (требуются права администратора и включённые Темы).
- Автоматическое создание тем в форуме при первом сообщении пользователя: имя темы соответствует имени пользователя.
- Кнопка «🤝 Взять тикет» и фиксация ответственного сотрудника.
- Панель поддержки `/panel` с действиями: закрыть обращение, позвать старшего, забанить пользователя.
- Передача обращения старшему сотруднику (@dn4ikx) и уведомления пользователя.
- Принудительное удаление сообщений от сотрудников, которые не закреплены за тикетом или отстранены.
- Двусторонняя пересылка сообщений, файлов и реакций между пользователем и темой.
- Автоматическое закрытие тикетов спустя 24 часа бездействия.
- Оценка работы поддержки (1–5) после закрытия обращения.
- Система зарплат: начисление за каждый закрытый тикет, история выплат, штрафы, баланс.
- Команда `/admin` (только для @dn4ikx) для управления командой поддержки: добавление сотрудников, изменение ставок, статистика, штрафы, отстранение.
- Команда `/me` для сотрудников с личной статистикой, балансом и настройкой реквизитов.

## Установка

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` рядом с проектом и укажите токен бота:

   ```env
   BOT_TOKEN=123456:ABCDEF...
   BOT_OWNER=dn4ikx          # опционально, если username владельца отличается
   DEFAULT_TICKET_WAGE=10    # опционально, ставка за тикет по умолчанию
   ```

## Запуск

```bash
python -m bot.main
```

После запуска выполните в целевой группе (форуме) команду `/link`, чтобы привязать её к боту. Все дальнейшие обращения пользователей будут автоматически появляться в теме форума.

## Структура проекта

- `bot/config.py` — загрузка настроек из окружения.
- `bot/database.py` — асинхронный слой работы с SQLite.
- `bot/main.py` — логика Telegram-бота и маршрутизация команд.

База данных SQLite (`support_bot.db`) создаётся автоматически в директории `bot/`.
